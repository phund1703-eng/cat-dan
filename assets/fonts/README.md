# Fonts

## BeVietnamPro-Bold.ttf

- **Font:** Be Vietnam Pro (Bold) — hỗ trợ đầy đủ tiếng Việt có dấu.
- **Nguồn chính thức:** Google Fonts — https://github.com/google/fonts/tree/main/ofl/bevietnampro
  (dự án gốc: https://github.com/bettergui/BeVietnamPro)
- **Giấy phép:** SIL Open Font License 1.1 (OFL-1.1) — toàn văn tại `OFL.txt` trong thư mục này.
  OFL cho phép dùng, nhúng và phân phối lại font trong sản phẩm (kể cả thương mại);
  không được bán riêng font, và khi phân phối lại phải kèm license này.
- **Dùng ở đâu:** phụ đề/thumbnail qua `config/settings.yaml` → `video.subtitle.font`
  (mặc định trỏ tới file này).

Tải lại/cập nhật font: chạy `python scripts/download_assets.py` ở thư mục gốc repo.
